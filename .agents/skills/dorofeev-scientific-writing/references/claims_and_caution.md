# Claims and caution

## Match the verb to the evidence

- `рассматривается`, `исследуется`: identify the object and task.
- `наблюдается`: describe a feature visible in a figure, table, or computed data when the mechanism is not independently established.
- `показано`: use when the stated analysis or calculation directly supports the conclusion.
- `установлено`: reserve for a systematic result supported by several consistent arguments or checks.
- `может приводить`: state a demonstrated possibility without claiming universality.
- `можно ожидать`: mark a hypothesis or next step and separate it from obtained results.

Avoid `доказывает` for numerical evidence unless a proof has actually been given.

## Separate three levels

1. **Observation:** what the data, figure, or table displays.
2. **Supported conclusion:** what follows from the stated analysis or verification.
3. **Hypothesis or interpretation:** what may explain the observation but still requires confirmation.

Do not move a statement to a stronger level during stylistic revision.

## Limit the scope

Use an explicit boundary when relevant:

- `для рассмотренных значений параметров`;
- `в рассматриваемой области`;
- `на принятой сетке`;
- `для первых шести частот`;
- `при указанных граничных условиях`;
- `в данном случае`.

A finite grid, one geometry, or one set of supports does not establish a universal law.

## Never create scientific content during style work

Do not:

- infer an unverified cause;
- introduce a new criterion or parameter domain;
- round or alter a value;
- call a discrepancy an error without a defined reference;
- declare one model true;
- claim tracking from sorted frequencies;
- infer form transformation without mode-shape evidence;
- import a term or mechanism from a different model without an applicability argument.

If evidence is missing, retain a neutral observation or state that the proposed interpretation is not confirmed.

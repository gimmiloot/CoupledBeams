# Отчёт для научного руководителя

[Редактируемый LaTeX](report.tex) и [печатный PDF](report.pdf), 26 страниц:
«Параметрическая неустойчивость свободных плоских колебаний двух жёстко
сопряжённых стержней». Изложение начинается с одного прямого стержня:
местные оси, шесть движений и независимое изменение толщины по полю c.
Далее раскрыты скалярные деформации, раздельные конститутивные вклады M–H
и Тимошенко, интегрирование по сечению и промежуточные вариационные шаги.
Приведены таблица размерностей, семь линейных и семь нелинейных скалярных
балансов, фактически решаемые кубические координатные уравнения и полностью
раскрытая плоская кубическая система. Затем вводятся два плеча, узел,
последовательность численных задач, Флоке и физический смысл результатов.
Два приложения позволяют восстановить каждый кубический коэффициент.
Из восьми рисунков пять являются собственными механическими схемами,
остальные используют прежние физические профили и динамические данные.
Ограничение одной самостоятельной поперечной деформации явно выделено.
PDF собран XeLaTeX с установленными fontspec, babel,
amsmath, graphicx, longtable и array; новые пакеты не устанавливались.

Это самостоятельный научный текст для обсуждения, не журнальная статья.
Область результата: β=15°, μ=0.1, A=0.005, тип II, Ψ=0, принятая семиполевая
модель. Внеплоскостной рост подтверждён в p12 и воспроизведён в p14;
PL neutral qualification остаётся PARTIAL. Не утверждается неустойчивость
реальной конструкции или всех плоских движений.

Из этой папки исходник собирается двумя проходами:

```powershell
xelatex --disable-installer -interaction=nonstopmode -halt-on-error report.tex
xelatex --disable-installer -interaction=nonstopmode -halt-on-error report.tex
```

В выполненной сборке auxiliary files сохранены в отдельном bundle.
Предпочтительный внешний output-directory позволяет оставить эту папку
только с исходником, PDF и рисунками. Требуется Times New Roman; доступны
русский babel и штатные XeLaTeX math fonts. Автоустановка пакетов выключена.

## Уравнение, обозначения и физический смысл

Для постоянного круглого сечения A=πR², Ip=πR⁴/2, G=E/[2(1+ν)],
m=ρA, J=ν²ρIp, H=ν²GIp:

```
m u_tt - J u_xxtt - EA u_xx + H u_xxxx = 0,
T = (1/2) integral (m u_t^2 + J u_xt^2) dx,
V = (1/2) integral (EA u_x^2 + H u_xx^2) dx,
H U'''' + (J omega^2 - EA) U'' - m omega^2 U = 0,
N = (EA - J omega^2) U' - H U''',  P = H U'',
U'=chi, chi'=P/H, N'=-m omega^2 U,
P'=(EA-J omega^2)chi-N.
```

Вариация V−ω²T даёт концевой член `[N δU + P δU']`, следовательно
наружные усилия слева −N,−P, справа +N,+P. Marais Γ′y=−N по (12).
Размерности: m kg/m, J kg·m, EA N, H N·m², N N, P N·m;
каждый член PDE имеет N/m. Частота f=ω/(2π), Hz.
Source eta Marais — ν, source mu — G, source lambda — ω².
Это не геометрические mu/eta и не проектная Lambda. У Попова λ=ω/c.

C означает U=U′=0; F означает N=P=0; UP означает U=P=0 (U=U″=0
при H>0), продольное закрепление со свободной дополнительной деформацией.
Второй порядок H=0 имеет только по одному условию на конец: U=0 или
N=0. Условия C четвёртого порядка к нему не приписываются. При J=0
это элементарная теория; при J>0 — Rayleigh–Love. При свободных концах
U=const, ω=0 — отдельная жёсткая мода. В положительную нумерацию не входит.

Подстановка sin(kx), k=nπ/L, даёт
ω²=(EA k²+H k⁴)/(m+J k²). Граничная матрица рассчитывается отдельно.
При H=J=0 получается продольная cos/sin часть `equations.tex`
(начало «Вид решения») и `src/my_project/analytic/formulas.py`;
сравнение ограничено этой редукцией, новая теория не заменяет базовую.

Параметры Marais: E=70e9 Pa, ρ=2700 kg/m³, ν=.33, радиусы .11/.138 m,
длины .20/.10 m; C-F, непрерывны U,U′,N,P, масс/пружин нет.
Геометрия короткая и толстая, сохранена по источнику. Это воспроизведение
его стержневой теории, не доказательство трёхмерной точности.
Для Попова используются только c,ν,d,L: уравнение делится на ρA,
коэффициенты 1, ν²d²/8, c², c²ν²d²/[16(1+ν)]. Нормировка на ρA
не задаёт вымышленных E,ρ; массовая норма здесь на единицу ρA.

## Численный контракт, установленный до расчёта

Один модуль `scripts/lib/bishop_longitudinal.py`, один CLI
`scripts/analysis/reproduce_bishop_literature.py`. Это новый контракт
четвёртого порядка для прямого стержня и литературных данных, а не preset
изгибного решателя. Повторно используются NumPy/SciPy, принятые
`--compute`, `--plot-only`, `--output-dir`; универсальный framework не создаётся.
Карта частот от параметра отсутствует; `frequency-map-v1` не применим.
Здесь sorted mode n при фиксированной постановке, без branch tracking.

Основной базис: cos(bx), sin(bx), exp(−ax), exp(−a(L−x)); все экспоненты
ограничены. При ω=0 используется полиномиальная пара 1,x. Масштабы состояния
(1,1/L,EAref/L,EAref), затем положительное выравнивание строк/столбцов.
Малый столбец не увеличивается до единичной нормы: для пониженной F-F
задачи целый столбец может обращаться в ноль на собственной частоте.
Производные cos/sin вычисляются циклом знаков, без численного cos(π/2).
Хранятся сингулярные числа, σmin/σmax и σmax/σпредпоследнее: полный
condition number в собственном значении ожидаемо бесконечен.

Поиск ограничен диапазонами и бюджетами в fixtures. Брент, максимум 100
итераций; допускается одно удвоение сетки при неуспехе. Все интервалы,
числа вычислений и причины сохраняются. Проверка Marais другим представлением:
expm независимо собранного состояния, только адресные корни, 50/70 разрядов.
Длинный стержень Попова transfer matrices не использует.
Для Marais выполняется численный подсчёт аргумента аналитического
определителя в прямоугольнике частот; удвоенная дискретизация контролирует
устойчивость подсчёта. Это конечная численная проверка, не общий WW-алгоритм.

Масштабированная граничная невязка ≤1e−8, дифференциальная ≤1e−10,
относительная энергия и массовая ортогональность ≤1e−7,
относительное расхождение независимых частот ≤1e−9; неособычная часть
матрицы condition ≤1e10. Точные определения и фактические значения
сохраняются с результатами. Эти допуски не являются допусками к публикации.
Print match Marais: четыре значащие цифры, отдельно округление к ближайшему
и усечение; интервалы в fixtures. Численные допуски не расширяются после
сравнения. Для рисунков без цифровых данных допустимо только визуальное сравнение.

Шесть категорий статуса оцениваются раздельно: SOURCE_TRANSCRIPTION,
EQUATION_AND_BC_CONSISTENCY, NUMERICAL_VERIFICATION, SOURCE_PRINT_MATCH,
MODE_SHAPE_COMPARISON, EXPERIMENT_REPRODUCTION. Общий статус конечного
этапа `completed` не означает совпадения со всеми напечатанными числами;
реализация остаётся `active-diagnostic` по назначению.

## Внутренние и независимые проверки

| Проверка (максимум) | Marais, 5 мод | Попов, 3 ν × 3 типа концов × 30 мод |
|---|---:|---:|
| Масштабированные все BC/стык | 1.66e−14 | 1.60e−9 |
| Относительная невязка ODE | 3.58e−16 | 4.76e−16 |
| \|K/(ω²M)−1\| | 4.45e−16 | 3.23e−12 |
| max\|G−I\| с вкладом J U′m U′n | 3.81e−16 | 1.66e−12 |
| σmax/σпредпоследнее | 2.237 | 1.932 |

Невязка BC: каждая строка в единицах U, Lχ, LN/EAref, P/EAref делится
на непрерывный max|U|. Невязка ODE: max|HU⁽⁴⁾+(Jω²−EA)U″−mω²U|
делится на max суммы модулей этих трёх слагаемых. G — Gram матрица форм
с единичной обобщённой массовой нормой. Квадратура Гаусса по каждому
участку и выделенным концевым слоям; основной порядок 256, Marais также
проверен при 64/128. Производные аналитические, интерфейс не интегрируется
через разрыв коэффициентов. Проверка знака сил включает интегральное
тождество виртуальной работы с независимым полиномиальным тестовым полем.
Здесь K=∫(EA U′²+H U″²)dx, M=∫(m U²+J U′²)dx; K/M проверяет ω².

Marais: независимый expm на 50/70 разрядах даёт максимум относительного
расхождения с основным базисом **2.07e−16**, между двумя точностями
**2.97e−45**. Всего 50+55 вычислений адресного определителя. Это две
проверки одной теории, не независимая экспериментальная валидация.
Попов: (13) и граничная система согласуются до **1.45e−13** относительно;
UP и (15) — до **1.50e−13**. Явная формула и граничный вычислитель
реализованы отдельно. Пониженные wave/Rayleigh–Love и Bishop при
искусственном разбиении однородного стержня совпадают до **1.83e−13**;
нулевая свободная мода имеет точно нулевую невязку и энергию.
Lean не обнаружен: использованы прямой вывод, размерностная проверка,
численные проверки многочлена и интегральных тождеств.

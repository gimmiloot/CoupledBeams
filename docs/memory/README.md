# Память RLB-2I/RLB-2J и поворотно-упругого узла EB/RLB

Этот небольшой слой помогает найти, что установлено, откуда это известно,
каковы ограничения и что осталось решить. Покрыты симметричные слоистые
стержни Reddy/FSDT: эквивалентные шестислойные ламинаты RLB-2I, попарные
переносы RLB-2J и необходимый контекст модели и верификации. Дополнительно
покрыт теоретический этап поворотно-упругого узла EB/RLB: новое решение —
[RLB-D03](decisions.md#rlb-d03), проверенный вывод и его ограничения —
[RLB-K05](knowledge.md#rlb-k05),
[самостоятельная заметка](../laminated_beams/inplane_rotational_spring_joint.md).

Порядок чтения: этот вход → [текущий контекст](current.md) → нужная запись
в [знаниях](knowledge.md) или [решениях](decisions.md) → конкретное основание
по её ссылке. Читать всю память перед каждой задачей не требуется.

Общая навигация: [индекс исследований](../research_index.md),
[индекс результатов](../results_index.md),
[тематический README RLB](../laminated_beams/README.md).
Отсутствие записи означает неполноту покрытия памяти, а не отсутствие исследования.

После содержательного результата или принятого решения обновляются только
затронутые записи и место остановки в `current.md`, в рамках разрешённых
изменений документации. Сохраняются условия, исходный статус, ссылка и
происхождение; расхождение источников отмечается явно. Косметическая правка
не требует новой научной записи. Покрытие меняется в рамках научной задачи,
без автоматического распространения на весь проект.

Память не заменяет model-specific contracts, теорию, код и данные, не меняет
иерархию научных источников и не разрешает новые действия. Содержательные
выводы пилота не переносятся автоматически на другие модели.

# Текущий контекст

## Покрытие и состояние

Память охватывает RLB-2I/RLB-2J, необходимые ограничения симметричной
Reddy/FSDT-модели, теорию поворотно-упругого узла EB/RLB, первый EB-пилот
и ограниченную проверку RLB → EB при той же конечной пружине; текущий этап —
EB-карты по углу для пяти состояний узла.
Остальные направления проекта здесь не обобщаются.

Последние содержательные результаты выбранного фрагмента:

- Подготовлены шесть EB-карт по углу для kappa=0,.1,1,100 и RIGID —
  [RLB-K08](knowledge.md#rlb-k08), [отчёт и рисунки](../laminated_beams/inplane_rotational_spring_eb_beta_maps.md).
  Из 1005 BASE-точек подтверждены 994, включая три guard qualifications;
  11 BASE-пропусков показаны разрывами. Десять точек переиспользованы,
  995 рассчитаны; из трёх добавленных углов подтверждены два.
- RLB с пружиной подключена узким адаптером; выполнены матричные сравнения
  и шесть групп `epsilon_limit=.01,.1,1`, beta=0°,30°, kappa=1 —
  [RLB-K07](knowledge.md#rlb-k07), [отчёт](../laminated_beams/inplane_rotational_spring_rlb_eb_limit.md).
  Все 36 целевых частот приняты; пять групп приняли guard, beta=0°, epsilon=1
  имеет отдельную guard qualification. Нулевой предел проверен в 14
  переиспользованных EB-корнях двух групп без нового поиска.
- Новый узел: подготовлена [теоретическая заметка](../laminated_beams/inplane_rotational_spring_joint.md).
  Выведены шесть условий для EB/RLB, матрица, энергетические и предельные
  соотношения — [RLB-K05](knowledge.md#rlb-k05). На первом EB-этапе подготовлены
  EB-модуль, целевые тесты и сценарий 12 групп — [RLB-K06](knowledge.md#rlb-k06),
  [отчёт](../laminated_beams/inplane_rotational_spring_eb_pilot.md).
  **EB исполняется; 50 целевых тестов пройдены, приняты 10/12 BASE-групп,
  сохранены 70 корней. Пилот частичный:** две группы `kappa=10000` отклонены
  по физической невязке; legacy regression RIGID при 30° не разрешила guard 7.
  При сохранённых усилиях сумма работы плеч
  и вариации энергии пружины равна нулю. Прежняя атрибуция ошибочного минуса
  заданию не подтверждена и снята; формулы и старые контракты не изменены.
- RLB-2I: `OVERALL: PASS`; нейтральное шестислойное семейство сохраняет
  редуцированную задачу, но различается по послойным напряжениям и энергиям
  в двух рассмотренных нагрузочных состояниях — [RLB-K02](knowledge.md#rlb-k02).
- RLB-2J: `RLB-2J: PASS`; три попарных переноса имеют изгибные рычаги
  1:2:3 и совпадающие спектры при одинаковом `D/D0` на объявленном наборе —
  [RLB-K03](knowledge.md#rlb-k03). Общий структурный вывод —
  [RLB-K01](knowledge.md#rlb-k01), пределы подтверждения —
  [RLB-K04](knowledge.md#rlb-k04).

Научный статус берётся из конкретных оснований. Прежние ограничения
source/Ritz-проверок не сняты новым теоретическим выводом.

## Согласованный этап и отложенные действия

Пользователь сообщил о решении с научным руководителем исследовать упругость
и вязкость **в месте сопряжения при плоских колебаниях**. Теоретический этап
поворотной упругости завершён. Первая EB-реализация и ограниченный пилот
выполнены по [RLB-D04](decisions.md#rlb-d04). Подключение пружины к RLB и
ограниченная проверка предела завершены по [RLB-D05](decisions.md#rlb-d05).
Новое задание разрешает шесть EB-карт по углу для пяти состояний узла —
[RLB-D06](decisions.md#rlb-d06). Пара EB/RLB нужна для согласованного перехода RLB → EB
с той же пружиной; широкое сравнение точности и критерий применимости не ставятся.

Происхождение: **новое решение пользователя, сообщённое в задании на узел**,
зафиксировано 2026-09-10, без предположения о дате встречи. Оно заменяет часть
RLB-D02 о невыбранном направлении — [RLB-D03](decisions.md#rlb-d03).
Согласование постановки не является её математическим доказательством.

Вязкость — последующий этап. `B != 0` и редактура старой синтетической
LaTeX/PDF-заметки отложены. Поступательная податливость, масса, эксцентриситет
узла, пространственное движение и изменение внешних опор не вводятся.
Запрет реализации и вычислений из RLB-D03 относился к завершённому
теоретическому заданию; ограничение «только EB» из RLB-D04 также историческое.
В текущем задании разрешена EB-карта на 201 общем угле от 0° до 90°
для kappa=0,.1,1,100 и точного RIGID, шесть sorted позиций и guard.
Поисковые окна прогнозируются по соседям; графики создаются отдельно из общей
таблицы. Прежний запрет углового sweep/рисунков больше не относится к этой задаче.
Старые отказы kappa=10000 и legacy RIGID guard 30° сохранены, их уточнение
не является предварительным условием. RLB-карты, epsilon_limit, вязкость,
Ritz/FEM/MAC, формы, новые материалы и изменение геометрии не разрешены.

## История EB-этапа

После уточнения пользователя 2026-09-10 найдено существующее окружение:
**`D:/python/Pycharm/pythonProject/.venv/Scripts/python.exe`**, Python 3.12.4,
numpy 2.1.3, scipy 1.15.2, pytest 8.3.4. Импорты и вычисления выполнены именно
им. `D:/python/python.exe` также существует, но без этих пакетов в его путях.
Прежний поиск через PATH/launcher был неполным; недоступный WindowsApps alias
не означает отсутствия Python. Зависимости не устанавливались, PATH не менялся.

На исходном HEAD продолжения `acb3078c497b9d3366b4d1ecb1f12b3e6f50db43`
проверены 50 тестов, 10 BASE-групп и конечные контроли. Результаты действительно
прочитаны из `results/laminated_beams/inplane_rotational_spring_eb_pilot/`:
CSV, diagnostics и manifest локальны и игнорируются Git; численный итог сохранён
в [tracked-отчёте](../laminated_beams/inplane_rotational_spring_eb_pilot.md).
Завершённые BASE-группы не пересчитывались при исправлении локальных контролей.

Максимальная принятая физическая невязка `1.099e-10`. Независимый прямой RIGID
reference и обе шарнирные группы прошли конечные проверки; большой конечный
предел `kappa=10000` не подтверждён. Два отказа физической невязки и неразрешённый
контроль guard у RIGID 30° требуют локального численного разбора; допуски не ослаблены.
История знака уточнена ранее без правки формул. Три текущих вопроса о реализации EB, результатах/ограничениях
и отсутствии RLB/вязкости проверены через память в том же контексте;
это навигационная проверка, не независимая верификация. Общий PASS не присвоен.
Блокер среды снят. Место остановки — частичный численный EB-пилот с явными
непринятыми случаями, без разработки нового метода ради полного результата.
На завершение EB-этапа RLB с новой пружиной и вязкость ещё не были реализованы;
последующее разрешение RLB задано отдельно в RLB-D05.

Документационный пилот RLB-2I/RLB-2J завершён ранее: его шесть навигационных
вопросов были проверены 2026-09-09, ограничения того задания являются историей
[RLB-D01](decisions.md#rlb-d01), а не текущим запретом на теоретическую работу.

## История проверки RLB → EB

2026-09-10, исходный HEAD `7eccc8a4b8d28f599cae53a325bed0a60a7c2583`, `main`,
чистое исходное дерево. Тем же Python 3.12.4 выполнены 76 целевых тестов
(26 RLB/ограниченный runner + 50 EB), конститутивные проверки, H/T/B при двух углах и трёх частотах.
Узел подключён к RLB; нулевой предел реализован через коэффициенты RLB,
без Infinity и без вызова EB-сборки вместо RLB. Принятые beta0_k1/beta30_k1
прочитаны с полной точностью; в 14 корнях проверены RLB-limit матрицы и невязки.

Шесть новых положительных-epsilon групп рассчитаны последовательно.
36 ROOT проходят строгие gates; пять guard приняты, один при beta=0°, epsilon=1
остаётся `NULLITY_UNRESOLVED_AT_1E-12`. Дополнительные подстановки сохранённых
частот подтвердили отдельный целевой диапазон; статус группы
`TARGET_CONFIRMED_GUARD_QUALIFIED`, а не безусловное завершение guard.
Максимальный физический остаток новых ROOT `2.270e-11`; e_max убывает к EB
для обоих углов — [RLB-K07](knowledge.md#rlb-k07).

На новые группы 15422 построения B (максимум 2664 на группу), две локальные
попытки, около 88 с измеренных вычислений вместе с матричной стадией и нулевым
пределом. Лишний поисковый хвост первого запуска до Omega=114 и исправление
условия остановки без повторного поиска отражены в отчёте. Исходные EB CSV/JSON
не изменены. Новые данные лежат в
`results/laminated_beams/inplane_rotational_spring_rlb_eb_limit/`;
они локальные/игнорируемые, содержательный итог — в
[tracked-отчёте](../laminated_beams/inplane_rotational_spring_rlb_eb_limit.md).

Проверка ограничена однородным изотропным четырёхслойным benchmark и конечным
набором; source/Ritz qualifications не сняты. Старые три EB-неопределённости
не уточнялись, вязкость не начата. Следующий этап не выбран этим заданием.
Память помогла найти теорию, принятую EB-опору и рабочий Python; устаревшее
ограничение «только EB» обновлено новым решением. Три вопроса об изменяемых
коэффициентах, матричных/спектральных проверках и старых отказах проверены
по маршруту README → RLB-D05/RLB-K07 → разделы отчёта в том же контексте.
Это проверка навигации, не независимая верификация механики.

Потрачено 807465 построений B, 12 дополнительных попыток; max 1099 B на точку.
Измеренное численное время по точкам 250.851 с; основной проход с записью
checkpoint 547.755 с. Максимальный физический остаток новых принятых ROOT
`9.247e-11`. Локальный audit исправил пропуск близкой шестой частоты при
kappa=.1, beta=90°; прежняя попытка сохранена. Нарушений порядка по жёсткости
на сравнимых принятых значениях больше нет. Два neighbour flags RIGID около
17.5° остаются; ADDED 17.75° и 11 BASE-точек не подтверждены.
Три qualifications guard при beta=.1° отделены от целевых шести позиций.
Карты частичные; общий PASS модели не присвоен.

Память помогла найти закон пружины, совместимые EB-данные и рабочий Python;
запрет углового sweep/графиков из прежних пилотов распознан как исторический
и заменён в объёме RLB-D06. Через README → RLB-K08 → разделы отчёта найдены

новая архитектура не потребовалась. Старые EB kappa=10000 и legacy guard
RIGID 30° не уточнялись, RLB-предел не повторялся, вязкость не начата.
Работа остановлена на сохранённой частичной карте; следующий разбор спектра
этим заданием не разрешён.

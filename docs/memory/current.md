# Текущий контекст

## 1. Текущее научное состояние

2026-09-27: малый EB weak-damping experiment [K19](knowledge.md#rlb-k19)
завершён: шесть состояний A/B/C при d=.001,.005. Упругий screening
правильно предсказал порядок затухания; относительная поправка к первому
приближению в этой выборке наибольшая у C.

Архитектура [K18](knowledge.md#rlb-k18): точно одинаковые EB-плечи —
reduced eta±, неодинаковые — full 6×6; полный путь сохранён как контроль.
[K20](knowledge.md#rlb-k20) устанавливает локальную чётность частоты
и нечётность затухания по вязкости без требования одинаковых плеч.

Текущего неразрешённого численного блокера для завершённого этапа нет.
Квалификации K18/K19, включая raw full-флаг C и малый частотный сдвиг
C/.001, сохранены; это не общий PASS спектра. Исторические отказы K16
не переписаны. [D19](decisions.md#rlb-d19) завершает документальный этап.

## 3. Открытое решение

Вероятное следующее направление — production-quality расширение
RLB/Timoshenko + KV и редкое сравнение EB/RLB. Это кандидат следующего
этапа, а не разрешение расчёта. Его физический объём, точки и критерии
ещё предстоит согласовать отдельным решением пользователя.

## 4. Действующие границы и остановка

Новые d/beta sweeps, crossing study, RLB-расчёты и уточнение точности
сейчас не разрешены. Документальный этап завершён; следующий физический
этап не начат. Теоретическая область K20 шире выполненной EB-выборки,
но не расширяет её численную верификацию. История и границы прежних
этапов находятся в D/K, а не образуют новый список обязательных расчётов.

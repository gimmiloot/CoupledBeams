# Решения о пилоте

## RLB-D01

**Принято:** ограниченный документационный пилот RLB-2I/RLB-2J из четырёх
файлов памяти, с минимальным подключением к `AGENTS.md`, корневому `README.md`
и `CHANGELOG.md`.

**Почему:** проверить, помогают ли короткие записи находить результат,
основания, ограничения и нерешённые вопросы, без отдельного проекта памяти.
**Область действия:** текущее задание; чтение источников, документальные правки
и проверка полезности. Расчёты, правка научных источников, инфраструктура,
охват всего репозитория и Git-записи в него не входят.
**Происхождение:** сообщено пользователем в задании на пилот.
**Пересмотр:** после оценки пользователем этого пилота и явного изменения
объёма задачи; ограничения задания не являются вечными запретами проекта.

## RLB-D02

**Принято:** организация памяти отделена от выбора следующего научного
направления. Упруго-вязкие опоры/соединение и `B != 0` остаются обсуждаемыми
вариантами, без утверждения реализации; правка теоретической заметки отложена.

**Почему:** окончательное продолжение исследования ещё не выбрано;
документационный пилот сам по себе не выбирает физическую модель.
**Область действия:** дальнейшие действия по покрытому RLB-фрагменту;
завершение RLB-2I/RLB-2J не означает исчерпания симметричного направления.
**Происхождение:** сообщено пользователем в задании на пилот, без отдельной
ссылки на разговор или предположений о согласовании с руководителем.
**Пересмотр:** явное решение пользователя о следующем научном этапе;
соответствующее обновление [текущего контекста](current.md).

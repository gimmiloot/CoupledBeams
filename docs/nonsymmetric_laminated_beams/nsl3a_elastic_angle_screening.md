## Показатели по упругим формам

Используется полная физическая масса
\[
\mathcal M=\sum_i\int_0^{L_i}
[m_i(u_i^2+w_i^2)+2j_{1i}u_i\psi_i+j_{2i}\psi_i^2]\,dx_i.
\]
Новые формы нормируются на \(\mathcal M=1\); у сохранённых форм
нормировка и коэффициенты остаются исходными. Пусть
\(\Delta\psi=\psi_1(L_1)-\psi_2(L_2)\). Тогда
\[
P=\frac{|\Delta\psi|^2}{\mathcal M},\qquad
s=\frac{D_{\rm ref}}{l_{\rm ref}}\frac{P}{\omega^2},\qquad
\Omega=\omega t_{\rm ref},\qquad G=\frac{\Omega s}{2}.
\]
Для простой изолированной моды ранее проверенная формула
\(\partial\omega^2/\partial k_\theta=P\) даёт
\(s=\partial\ln\omega^2/\partial\kappa_\theta\).
В настоящем расчёте дополнительные значения жёсткости не используются.
\[
\alpha_{\rm pred}=\frac{c_{\rm ref}P}{2},\qquad
\zeta_{\rm pred}=d_\theta G
=\frac{d_\theta D_{\rm ref}t_{\rm ref}P}{2l_{\rm ref}\omega}
=\frac{\alpha_{\rm pred}}{\omega}.
\]
Два представления согласованы с максимальной относительной разностью
\(4.27\cdot10^{-16}\). Это прогноз первого порядка по вязкости;
\(\omega\) здесь упругая частота, а не \(\Im p\).

## Точная симметрия и отсортированные позиции

Для MIRROR \(H_2=T_rH_1T_r\),
\(T_r=\operatorname{diag}(1,-1,-1,1,-1,-1)\), и
\(\mathcal S(y_1,y_2)=(T_ry_2,T_ry_1)\).
При одинаковых длинах и исходных заделках \(\mathcal S^2=I\).
В физических строках полной граничной матрицы
\(B(\omega)\mathcal S=W(\beta)B(\omega)\), где невырожденное преобразование
строк \(W\) получено в NSL-3A. Изменение \(\beta\) не нарушает этого тождества.
Это сопоставление проводится до нормировки строк.

Для функционала \(l y=\psi_1-\psi_2\) тождественно
\(l(I-\mathcal S)/2=0\). Поэтому на классе \(\eta=-1\)
\(\Delta\psi=P=s=G=\alpha_{\rm pred}=\zeta_{\rm pred}=0\) точно.
Численные остатки \(\Delta\psi\) и \(P_{\rm numeric}\) сохранены отдельно.
Формы не проецировались на класс и не подправлялись ради получения нуля.
Класс устанавливался по полной массовой норме
\(\|\mathcal S\phi-\eta\phi\|_M/\|\phi\|_M\).

Матрицы при всех пяти углах прошли проверку: ранг узла 6;
относительная невязка коммутатора MIRROR \(2.35\cdot10^{-16}\),
граничного тождества не более \(6.90\cdot10^{-16}\).
Для SAME_LOCAL коммутатор имеет относительную норму .01414;
прежняя отражательная симметрия отсутствует. Этому случаю
не назначены классы и не введены структурные нули.

| β | Защищённые позиции MIRROR среди 1–6 | Активные позиции |
|---:|---|---|
| 15° | 2, 4, 6 | 1, 3, 5 |
| 30° | 1, 4, 6 | 2, 3, 5 |
| 45° | 1, 4, 6 | 2, 3, 5 |
| 60° | 1, 4, 6 | 2, 3, 5 |
| 75° | 1, 4, 6 | 2, 3, 5 |

Различие первых двух номеров при 15° и 30° не является утверждением
о прослеженном пересечении: таблица содержит независимые отсортированные спектры.

Использован неизменный `CoupledBeams.prefix` NSL-2: инерция симметричной
матрицы Дирихле–Неймана точных коротких участков на допустимом пространстве
следов, затем Brent для определителя на интервалах скачка счёта на единицу.
Пространство узла содержит два общих перемещения и два независимых поворота.
64 участка на каждом плече используются для счёта, это не новая FEM-модель.
Нижняя оценка собственной частоты внутренних DD-участков сохраняет применимость
счёта; физика, масштабы состояния и критерии NSL-2 не менялись.
Для каждого префикса сохранены интервалы со счётами
\([0,1],[1,2],\ldots,[6,7]\), отсутствие дублей и принятый guard.
Таким образом, полнота основана не только на наличии семи решений.

Прежняя верхняя пробная оценка \(\omega_{\rm upper}=8\) нужна API
проверенного счётчика. Запрос инерции при этой границе возвращает 20,
но **корни 8–20 не выделялись и не рассчитывались**.
Новый алгоритм локального счёта ради сужения этой оценки не вводился.
Соседние сохранённые частоты записаны как прогнозы; имеющийся API
не принимает локальные окна, поэтому они не заменяли изоляцию по счёту.
Нет повторного Ritz, независимого широкого сканирования или `certified_audit`.
Максимальное отношение соседних отсортированных частот 1.333675 < 2;

## Ограниченное сопоставление форм

Использована общая физическая метрика равноплотного семейства:
локальные \((u,w,\psi)\) переводятся через проверенные
\(G_i(\beta)\) в \((d_X,d_Y,\psi)\) при одинаковых \(x_i/L_i\).
Масса в этих координатах \(\operatorname{diag}(m,m,j_2)\), так как здесь
\(j_1=0\). Ошибочное сравнение локальных компонент при разных углах
проверено отрицательным тестом. Формула не распространяется молча
на другую семью с ненулевой смешанной инерцией.

Принятие: взаимный максимум MAC ≥.90, отрыв от следующего кандидата
в строке и столбце ≥.10, среди шести основных форм.
MAC — конечное сопоставление выбранных форм, **не непрерывное продолжение**.

- MIRROR↔SAME_LOCAL при 15° и 45°: позиции 1–6 сопоставлены попарно.
- При 30° позиции 1/2 остаются UNRESOLVED (MAC ≈.851);
  позиции 3–6 согласованы с NSL-2.
- При 60° позиции 3/4 UNRESOLVED (лучшие MAC ≈.632/.630);
  остальные попарные назначения приняты.
- При 75° приняты MIRROR 3 ↔ SAME_LOCAL 4 (MAC .945054)
  и MIRROR 4 ↔ SAME_LOCAL 3 (.945818). Остальные позиции совпадают.
  Поэтому сильное участие SAME_LOCAL 4 при этом угле нельзя приписать
  именно форме из защищённого класса MIRROR 4.
- Относительно **исходных форм 4/6 при 30°** оба расположения допускают
  сопоставление с теми же номерами при 15° и 45° (MAC .940641–.965879).
  При 60° и 75° эти сопоставления UNRESOLVED; новые углы для их уточнения
  не рассчитывались.

Для принятого сопоставления SAME_LOCAL 4, 30°↔45°:
\(P=689.31986,\alpha_{\rm pred}=4.97473759\cdot10^{-5},
\zeta_{\rm pred}=7.19158225\cdot10^{-5}\) при 45°;
рост относительно 30° составляет 3.64705/3.64899 раза.
Для формы 6 при 45°:
\(\alpha_{\rm pred}=9.42632665\cdot10^{-6},
\zeta_{\rm pred}=6.75506321\cdot10^{-6}\), рост 2.08340/2.09485 раза.
Таким образом, даже при принятом конечном сопоставлении участие меняется,
но эти абсолютные значения существенно меньше сеточного максимума позиции 5.

## Вывод и ограничения

**Точно:** защита класса MIRROR \(\eta=-1\) сохраняется для всех рассматриваемых
углов. Номер защищённой позиции может меняться. SAME_LOCAL не обладает
этой отражательной инвариантностью.

**Численно принято:** десять полных префиксов 6+1, восемь новых;
все физические критерии пройдены, прежние предикторы воспроизведены.
38 регрессий первоначального запуска и две дополнительные проверки
cache/сохранённых коэффициентов дают 40 адресных тестов.
163 защищённых исходных файла сохранены, предыдущие D/K-записи — побайтно.
Повторный `--compute` использует проверенный cache: ноль новых solves.

**Предварительное наблюдение:** слабое участие SAME_LOCAL 4/6 при 30°
не описывает все первые шесть форм и всю заданную сетку.
Наиболее высокий предиктор здесь получен для SAME_LOCAL 15°, позиции 5;
также выделяется SAME_LOCAL 75°, позиция 4, с указанной оговоркой об идентичности.
Это возможные объекты отдельного комплексного подтверждения, которое
в данном этапе **не выполнялось**.

Максимум \(\alpha_{\rm pred}/\omega=\zeta_{\rm pred}=.00198552\)
составляет около .199%, то есть абсолютные коэффициенты остаются малы.
Однако малость этого отношения сама по себе не подтверждает точность
слабовязкого прогноза при новом угле. Фактическое затухание там не установлено.
Максимумы относятся только к пяти углам и первым шести позициям;
они не являются глобальными или оптимальными. Дальнейшие карты,
crossing/veering, NSL-3B, FRF и новые комплексные расчёты не начаты.

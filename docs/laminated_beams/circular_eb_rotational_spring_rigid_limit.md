# Круглые EB-стержни: поворотная пружина и точный жёсткий узел

**Статус: completed — ограниченная 1D-диагностика**, 2026-10-05.
Заметка сохраняет научный итог локальной проверки по вопросу рецензента
о жёсткости углового соединения. Это два изотропных круглых стержня
Euler–Bernoulli с продольным движением. Размещение рядом с
[теорией поворотной пружины](inplane_rotational_spring_joint.md)
обусловлено общим механизмом узла; результаты не относятся к ламинатам,
прямоугольным анизотропным стержням, RLB/Timoshenko или Kelvin–Voigt.
Сводка составлена из сохранённых результатов; при её подготовке расчёты
не повторялись. Решение и краткий результат: [D25](../memory/decisions.md#rlb-d25),
[K26](../memory/knowledge.md#rlb-k26).

## Постановка и воспроизводимость

Параметры: \(E=2.1\cdot10^{11}\) Па, \(\rho=7800\) кг/м³,
\(r=0.005\) м, \(L_{\rm total}=2\) м, \(l=1\) м,
\(\mu=0.30\), \(\beta=15^\circ\). Длины плеч равны 0.7 и 1.3 м.
Безразмерная поворотная жёсткость — \(\kappa_\theta=k_\theta l/EI\).
Основные состояния: \(1,10,100\) и точный `RIGID`, заданный связью,
а не большим конечным значением жёсткости.

Использованы готовые компоненты:

- [baseline formulas](../../src/my_project/analytic/formulas.py): `BeamParams`,
  `segment_lengths`, `lambdas_to_frequencies`, `assemble_clamped_coupled_matrix`;
- [EB spring kernel](../../scripts/lib/inplane_rotational_spring_eb.py):
  `EBArm`, `Joint`, `boundary_assembly`, `endpoint_diagnostics`;
- [generic solver](../../scripts/lib/general_spectrum_completeness.py): публичный
  `resolve_matrix_spectrum` с неизменными штатными настройками;
- [EB modes](../../scripts/lib/inplane_rotational_spring_eb_modes.py):
  `quadrature`, `arm_states`, `mass_vector`, `mac_matrix`, `assign`.

Новый физический или вспомогательный модуль не создавался.
[Диагностический runner](../../scripts/analysis/joint_review/check_circular_eb_spring_spectrum.py)
объединяет эти компоненты. Его три режима и порядок воспроизведения указаны
в [script inventory](../../scripts/README.md#circular-eb-springrigid-reviewer-diagnostic).
Частоты вычислялись в baseline-нормировке \(\Lambda\), через штатный
перевод в Гц; формы и MAC использовали физические массовые векторы.

Generic solver штатно искал 12 корней. Научная цель — первые шесть
отсортированных значений и контрольный корень 7. `TARGET_PREFIX_PASS`
является статусом этой диагностики; исходный `spectrum_status` solver
сохранён отдельно. Проверялись наличие и порядок корней, согласие
primary/verification, nullity, штатные root-quality gates, отсутствие
неразрешённых событий ниже guard и достаточный проверенный диапазон за ним.

## История остановок и спектральный результат

Ранний pilot на основе `pilot_inplane_rotational_spring_eb.py` остановился
при \(\kappa=1\) около 204.287 Гц с `UNRESOLVED_CLOSE_CANDIDATES`.
Последующие заранее заданные попытки A/B/C также не завершились.
[EB-JOINT-K01](../memory/knowledge.md#eb-joint-k01) и
[EB-JOINT-K02](../memory/knowledge.md#eb-joint-k02) остаются историческими
записями этих остановок. Они не доказывают физическую кратность и не
опровергают spring-модель. Старый solver не исправлялся.

При использовании другого существующего workflow — generic solver —
exact `RIGID` сопоставлен с circular baseline тем же solver:
`RIGID_TARGET_PREFIX_PASS`, первые семь корней простые, согласие
primary/verification подтверждено. Максимум расхождения первых семи
\(\Lambda\) равен \(3.015614424839441\cdot10^{-10}\), относительного —
\(2.4135888671254965\cdot10^{-11}\).

**Эквивалентность полного 12-root спектра не подтверждена.** Около
\(\Lambda=18.139529\) различается численная SVD-nullity classification:
kernel-событие с nullity 2 занимает позиции 11–12, тогда как baseline
даёт простую позицию 11 и следующий корень на позиции 12.
Максимальное полное расхождение \(\Lambda\) — 1.5131870750992.
Эта `HIGHER_SPECTRUM_QUALIFICATION` сохранена; она не исправлена и
не переносится на разрешённые позиции 1–7.

Для \(\kappa=1\) generic solver видит около прежней проблемной частоты
одно простое событие на sorted position 5: \(f=204.287066572630\) Гц,
\(\Lambda=9.947391091135351\), без cluster. Primary и verification
расходятся по \(\Lambda\) примерно на \(1.83\cdot10^{-11}\).
Это результат нового workflow; прежняя остановка остаётся фактом.

Все четыре основных состояния прошли target prefix. Для каждой позиции
\(j=1,\ldots,6\) сохранённые значения удовлетворяют

\[
\Lambda_j(1)<\Lambda_j(10)<\Lambda_j(100)<\Lambda_j(\mathrm{RIGID}).
\]

Относительное отличие \(\delta_{\Lambda,j}
=|\Lambda_j(\kappa)-\Lambda_j^{\rm RIGID}|/\Lambda_j^{\rm RIGID}\)
уменьшается во всех шести позициях. Этот результат относится к независимо
отсортированным спектрам; сам по себе он не устанавливает соответствие форм.

## Формы и продолжение локальных мод

Из сохранённых корней восстановлены все 28 форм позиций 1–7 четырёх
основных состояний. Физические реакции восстановлены после снятия
матричного масштабирования. Поля построены на фактических плечах;
масса включает поступательные перемещения обоих плеч и нормирована
к \(M=1\), с quadrature(129). Симметрийная проекция не применялась.
Все штатные gates пройдены: максимальная нормированная физическая невязка
\(1.3356\cdot10^{-10}\), boundary/null residual
\(1.9495\cdot10^{-16}\), ошибка нормировки массы
\(4.4409\cdot10^{-16}\).

Seeds `k1_seed_01`–`k1_seed_06` — локальные descendants от \(\kappa=1\),
не канонические project branch IDs. Global assignment использует только
mass-weighted MAC с неизменными порогами \(MAC\ge0.95\), \(margin\ge0.20\)
и семью кандидатами, включая guard. Частота, \(\Delta\psi\) и sensitivity
не входят в стоимость или критерий выбора соответствия.

Прямой шаг `DIRECT_1_TO_10` прошли только seeds 01 и 04. Для 02,03,05,06
MAC равен соответственно 0.9430, 0.9252, 0.8671, 0.8731 при достаточных
margins. Их прежние `UNRESOLVED` сохранены. Ограниченное продолжение
по логарифму жёсткости добавляло точки только при отказе локального MAC,
по [существующему методологическому precedent](inplane_rotational_spring_eb_hinge_comparison.md),
без переноса его симметрийной классификации.

Для всех шести seeds подтверждён один путь:

\[
1\to3.162278\to5.623413\to10\to17.782794\to31.622777
\to100\to\mathrm{RIGID}.
\]

Четыре новые физические точки прошли target-prefix и reconstruction gates
(ещё 28 форм). Точки \(10^{1/4}\), 56.234133 и 1000 не потребовались.
Минимальные MAC и margin **принятых локальных шагов** — 0.9681420766
и 0.9367321400. Все шесть получили `FULL_KAPPA_PATH_CONFIRMED`.
Endpoint mapping при 10 совпадает с прежним direct best assignment;
`PATH_MAPPING_CONFLICT` и смен sorted position нет. Это не делает
неудачные direct MAC успешными задним числом.

## Относительный поворот и чувствительность

После нормировки массы измерялось \(|\Delta\psi|=|\psi_1-\psi_2|\).
Для простого собственного значения конечной пружины использовалось

\[
s=\frac{D_{\rm ref}}{l_{\rm ref}}
\frac{|\Delta\psi|^2}{\omega^2M}
=\frac{d\ln\omega^2}{d\kappa_\theta},\qquad M=1.
\]

Для exact `RIGID` эта производная не интерпретируется: `s` не задана.
Для его первых семи форм \(\max|\Delta\psi|=1.5500809525\cdot10^{-9}\)
при указанной массовой нормировке; нормированные angular residuals
проходят штатный physical gate. Это абсолютное массово-нормированное
число не следует сравнивать напрямую с порогом нормированной невязки.

У пяти из шести descendants обе величины уменьшаются вдоль проверенного
пути, включая промежуточные точки. У seed 06 от 1 до 10
\(|\Delta\psi|\) увеличивается на 2.95634%, а \(s\) — на 4.53756%;
далее они уменьшаются на конечных точках, а в `RIGID` выполнена связь
\(\Delta\psi\approx0\). Этот результат сохранён при подтверждённом MAC.
Монотонность sorted frequencies не требует монотонности этих величин.

Для всех шести \(|\Delta\psi|(100)<|\Delta\psi|(1)\), и формы прослежены
до exact `RIGID`. Поддерживается подавление относительного поворота при
приближении к жёсткому узлу в данном EB-примере; универсальная строгая
монотонность для каждой моды не установлена. Локальная sensitivity \(s(\kappa)\)
и конечное отличие частоты от `RIGID` характеризуют разные величины;
расхождение ранжирования мод по ним не является противоречием.

## Литературное основание и границы интерпретации

Ниже разделены четыре уровня обоснования. Локальные PDF и фактически
прочитанные места зарегистрированы в [source index](../literature/source_index.md#junction-sources-2026-10-05).
Внешний поиск, независимая проверка доказательств и новые выводы формул
в этом документационном этапе не выполнялись.

1. **Асимптотические условия из теории упругости.** Leugering–Nazarov–Slutskij
   (2019), §1.2, (1.7), §2.4, рассматривают плоские тонкие балки и
   непрерывность вращения в предельной задаче; условия существенно
   зависят от закрепления и подвижности элементов. Kerdid–Messaoudi
   (2026), §1, Lemma 2 / (33), §5, получают из пространственной
   задачи предельные условия, сохраняющие прямой угол двух стержней.
   Их спектральная постановка и прямоугольная геометрия не тождественны
   нашему круглому продольно-изгибному примеру. Kerdid (1997) — более
   ранняя задача с одним закреплённым концом; Nazarov–Slutskij (2002, 2016)
   уточняют роль подвижности и граничных условий. Эти источники обосновывают
   класс предельных условий; они не доказывают точность именно наших шести
   уравнений для произвольной конечной толщины.
2. **Баланс на области узла.** Наклон сечений не препятствует общему
   балансу результирующих \(\mathbf F_i=\int_{\Gamma_i}\sigma n\,dS\),
   выраженных в общей системе координат. Для моментов относительно общей
   точки учитываются \(\mathbf r_i\times\mathbf F_i\). При конечном узле
   они не объявляются нулевыми; в динамике учитываются также инерционные
   члены области узла. Баланс точечного безмассового узла — отдельная
   идеализация действующей 1D-модели, не новый вывод для конечной области.
3. **Условная оценка масштаба жёсткости.** Для геометрически подобного
   компактного монолитного узла размера порядка \(r\), с модулем того же
   порядка, ранее обсуждённый scaling argument имеет вид
   \(k_\theta\sim CEr^3\), \(EI\sim Er^4\), откуда
   \(\kappa_\theta\sim C_*l/r\). Лишь при фиксированном положительном
   \(C_*\) уменьшение \(r/l\) ведёт к росту \(\kappa_\theta\).
   Kolpakov–Andrianov (2014), pp. 818–819, прямо ограничивают свой
   асимптотический подход узлами сопоставимого с диаметром размера и
   сопоставимых упругих свойств. Это подтверждает необходимость оговорок,
   но не определяет \(C\) нашего узла. Мягкий слой, шарнир, глубокая выточка,
   специально податливое соединение или иной scaling свойств сюда
   автоматически не входят.
4. **Собственный численный результат.** Конечный набор расчётов проверяет
   тенденцию `SPRING -> RIGID` для шести низших descendants одной
   1D EB-системы. Он не определяет физический \(k_\theta\), коэффициент
   \(C\), ошибку при конечном \(r/l\), continuum calibration или FEM-согласие.
   Это не доказательство предела для всего спектра или всех геометрий.

Эта интерпретация относится к вопросу рецензента и не добавлена в общие
baseline assumptions статьи. Проверенные equations и физические модели
остаются прежними. Следующий выбранный вопрос — обоснование условий
сопряжения и баланса и границ thin-joint asymptotics; локальная FEM-калибровка
реального узла отложена пользователем. Новые расчёты отсюда не следуют.

# RLB-2F: одноплечевой слоистый контраст жёсткости

## Цель и область расчёта

Этап RLB-2F задаёт конечную частотную карту первых восьми независимо
упорядоченных частот жёстко сопряжённых стержней. В первом плече изменяется
распределение жёсткости между наружными и внутренними слоями, а второе плечо
остаётся однородным. Для описания контраста используется один знаковый
параметр \(\xi\): отрицательные значения соответствуют более жёстким
внутренним слоям, положительные — более жёстким наружным слоям.

Карта строится по общей политике
[`frequency-map-v1`](../numerics/frequency_map_computation_policy.md).
В каждой точке рассматриваются независимо отсортированные значения. Формы,
идентичность модальных ветвей, MAC и распределения энергии не вычисляются.

## Замороженная геометрия и физическая модель

Используется геометрический контракт RLB-2E:

\[
\mu=\tau=0,\qquad \beta=30^\circ,\qquad L_1=L_2=l=1,
\]

\[
b_1=b_2=b_0=0.20,\qquad h_1=h_2=h_0=0.05,\qquad K=5/6.
\]

Внешние концы защемлены. Плечи соединены прежним идеальным жёстким узлом.
Уравнения движения, порядок переменных состояния, координатный контракт,
матрица узла и критерии качества корней не изменяются.

Каждое плечо представлено четырьмя равными слоями толщины
\(h_{\mathrm{ply}}=h_0/4=0.0125\). Стопки записываются снизу вверх в
координате `z_project`. Во всех слоях принято `angle_deg = 0`.

## Базовый материал и параметр \(\xi\)

Базовый слабо ортотропный материал \(M_0\) совпадает с материалом RLB-2E:

\[
E_{1,0}=1.1,\qquad E_{2,0}=0.9,\qquad \nu_{12,0}=0.3,
\]

\[
G_{12,0}=G_{13,0}=G_{23,0}=1/2.6,\qquad \rho_0=1.
\]

Для наружных слоёв первого плеча вводится материал
\(M_{\mathrm{outer}}(\xi)\):

\[
E_{1,\mathrm{outer}}=(1+\xi)E_{1,0},\qquad
E_{2,\mathrm{outer}}=(1+\xi)E_{2,0},
\]

\[
G_{ij,\mathrm{outer}}=(1+\xi)G_{ij,0},
\qquad ij\in\{12,13,23\}.
\]

Для внутренних слоёв используется материал
\(M_{\mathrm{inner}}(\xi)\):

\[
E_{1,\mathrm{inner}}=(1-\xi)E_{1,0},\qquad
E_{2,\mathrm{inner}}=(1-\xi)E_{2,0},
\]

\[
G_{ij,\mathrm{inner}}=(1-\xi)G_{ij,0},
\qquad ij\in\{12,13,23\}.
\]

Для обоих материалов сохраняются
\(\nu_{12}=\nu_{12,0}\) и \(\rho=\rho_0\). Рассматривается диапазон
\(-0.8\leq\xi\leq0.8\); поэтому минимальный множитель модулей равен 0.2.
Обозначения H и L не используются как постоянные имена материалов, поскольку
их физическая роль меняется при изменении знака \(\xi\).

## Контракт стопок

Первое плечо имеет палиндромную слоистую стопку

```text
M_outer / M_inner / M_inner / M_outer
```

и роль `LAYERED`. Второе плечо имеет однородную reference-стопку

```text
M0 / M0 / M0 / M0
```

и роль `HOMOGENEOUS_REFERENCE`. При \(\xi=0\) обе стопки совпадают.
Перестановка ролей плеч применяется только в отдельной проверке симметрии и
не образует вторую plotted configuration.

## Аналитический constitutive contract

Пусть \(D_0\) — редуцированная изгибная жёсткость однородного плеча
`M0/M0/M0/M0`. Для слоистого плеча аналитический контракт имеет вид

\[
\frac{D_{\mathrm{layered}}(\xi)}{D_0}=1+\frac{3\xi}{4}.
\]

Отсюда следуют контрольные значения

| \(\xi\) | \(D_{\mathrm{layered}}/D_0\) |
| ---: | ---: |
| -0.8 | 0.4 |
| 0 | 1.0 |
| 0.8 | 1.6 |

В отличие от конфигурации `ANTI_PHASE` этапа RLB-2E, суммарная изгибная
жёсткость двух плеч здесь не сохраняется:

\[
\frac{D_{\mathrm{total}}(\xi)}{D_0}=2+\frac{3\xi}{4}.
\]

Равные объёмы материалов с множителями \(1+\xi\) и \(1-\xi\) требуют
постоянства матрицы \(A\), поперечной сдвиговой матрицы, \(I_0\) и \(I_2\).
После одномерной редукции должны оставаться постоянными
\(A_{\mathrm{beam}}\), \(S_{\mathrm{beam}}\), \(m\) и \(J\). Для обеих
палиндромных стопок должны выполняться \(B\simeq0\) и \(I_1\simeq0\).

Constitutive gate проверяет эти соотношения при
\(\xi=-0.8,-0.4,0,0.4,0.8\) с замороженными допусками RLB-2E. Спектральный
расчёт разрешён только после прохождения этого gate.

## Локальный контракт частотной карты

```yaml
frequency_map_policy: frequency-map-v1
calculation_mode: fast_plot
spectrum_semantics: sorted_positions
sweep_parameter: xi
parameter_grid: -0.80:0.02:0.80
continuation_anchor: 0.00
continuation_paths:
  - 0.00:-0.02:-0.80
  - 0.00:0.02:0.80
K_plot: 8
K_guard: 9
guard_root_role: completeness_only
neighbour_audit: enabled
local_repair_policy: triggered_only
strict_audit_default: false
branch_tracking: false
mac: false
mode_shapes: false
energy_analysis: false
```

Сетка содержит 81 основную точку. Центральная точка вычисляется один раз,
после чего расчёт продолжается отдельно к отрицательному и положительному
концам диапазона.

В каждой точке сохраняются позиции 1--8 и root 9. Контрольный корень проверяет
полноту plotted range и не выводится на рисунок.

Корни с позициями 10 и выше по умолчанию не вычисляются.

Прогноз по соседним точкам задаёт только локальные интервалы поиска. Каждое
итоговое значение должно быть получено существующим determinant/SVD detector
и refiner и пройти прежние критерии качества. Контроль соседних значений
служит только для обнаружения численных аномалий. Подозрительная точка
пересчитывается локально без сглаживания и без замены частоты интерполяцией.

## Нормировка

Используется нормировка RLB-2D и RLB-2E:

\[
A_0=b_0h_0,\qquad I_{y0}=\frac{b_0h_0^3}{12},
\]

\[
\Omega=\omega l^2\sqrt{\frac{\rho_0A_0}{E_0I_{y0}}},\qquad
\Lambda=\sqrt{\Omega},
\]

где \(E_0=\rho_0=l=1\), \(b_0=0.20\) и \(h_0=0.05\). Нормировка не
зависит от \(D_{\mathrm{layered}}\) или \(D_{\mathrm{total}}\).

## Результаты выполнения

Constitutive gate получил статус `PASS`. Карта содержит 81/81 основных точек,
729 строк `BASE` и 81 контрольный root 9. Neighbour audit отметил 13 точек;
все 13 локальных проверок получили статус `REPRODUCED_AFTER_LOCAL_REPAIR`.
Неразрешённых точек нет. Дополнительно сохранено 117 строк
`LOCAL_REFINEMENT`; сглаживание не применялось.

Production benchmark дал консервативную оценку 480.4524504 s при предельном
времени 2700 s. Расчёт спектра занял 88.3256274 s, а повторная отрисовка —
0.5846737 s. Сумма измеренных времён workflow равна 88.9103011 s;
максимальный RSS составил 136572928 bytes. Выполнено 311503 determinant и
311503 SVD/sigma evaluations. Максимальные значения
\(\sigma_{\min}/\sigma_{\max}\) и boundary residual среди основных корней
равны соответственно \(8.556713\cdot10^{-17}\) и
\(1.978775\cdot10^{-16}\).

При \(\xi=-0.8\) выполнено локальное плотное согласование determinant- и
sigma-detectors для контрольного root 9. Оно сохранено как численный
provenance полноты нижней части спектра. Принятый inventory содержит только
позиции 1--8 и root 9; root 10 в нём не вычислялся и не сохранялся.

Проверка перестановки плеч получила статус `PASS`. Максимальная относительная
разность по \(\Omega\) равна \(2.082688\cdot10^{-12}\). При \(\xi=0\)
matrix residual относительно однородной конструкции равен нулю. Дополнительное
сопоставление с сохранённым спектром RLB-2E дало максимальную относительную
разность \(9.099738\cdot10^{-13}\).

Относительные изменения \(\Lambda\) между концами сетки равны:

| Позиция | Относительное изменение |
| ---: | ---: |
| 1 | 0.2039295337 |
| 2 | 0.1167756258 |
| 3 | 0.1459671252 |
| 4 | 0.1242564814 |
| 5 | 0.1737440541 |
| 6 | 0.1478149907 |
| 7 | 0.04359360513 |
| 8 | 0.1360418951 |

Все восемь упорядоченных позиций имеют классификацию `NONDECREASING` на
принятой сетке. Минимальный соседний интервал равен
\(\Delta\Lambda=0.1902033479\) при \(\xi=-0.66\) между позициями 7 и 8.
Это значение является только диагностикой близости соседних упорядоченных
частот.

## Статус и ограничения

```text
RLB-2F: PASS
```

Этап относится только к указанной геометрии, четырём равным слоям с
ориентацией \(0^\circ\), материалу \(M_0\) и конечной сетке \(\xi\). Карта не
определяет идентичность модальных ветвей. Сближение соседних упорядоченных
позиций может быть отмечено только как кандидатный интервал для отдельного
последующего анализа форм.

Branch tracking, MAC, формы, локализация, crossing, veering, анализ энергии,
Ritz, FEM, damping, complex roots, certified audit и дополнительный
спектральный хвост в контракт RLB-2F не входят.

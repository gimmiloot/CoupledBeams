# Графики спектральных позиций при изменении \(\mu\) и \(\beta\)

## Область расчёта

Этап RLB-2D продолжает расчётный contract RLB-2C для трёх моделей двух
жёстко сопряжённых стержней прямоугольного сечения: модели
Эйлера--Бернулли, прежней изотропной модели Тимошенко и слабо ортотропной
RLB-модели case A. Рассматриваются две конечные сетки:

\[
\beta=15^\circ,\qquad \tau=0,\qquad
\mu=0,0.02,\ldots,0.80,
\]

\[
\mu=0.5,\qquad \tau=0.2,\qquad
\beta=0^\circ,1^\circ,\ldots,90^\circ.
\]

Для каждой точки сохраняются первые восемь положительных частот и девятый
контрольный корень. Соединённые на графиках значения являются независимо
упорядоченными спектральными позициями. Продолжение собственных форм между
соседними точками не выполняется.

Исходный шаг \(\Delta\mu=0.01\) был заменён разрешённым запасным шагом
\(0.02\) до просмотра спектральных результатов. Основанием послужил
предварительный runtime benchmark: полный frozen inventory для крайней точки
\(\mu=0.8\) не завершился за 350 s. Диапазон поиска, его сетки и пороговые
значения при этом не менялись.

## Нормировка частоты

Для всех трёх моделей используется одна reference normalization:

\[
\Omega=\omega l^2\sqrt{\frac{\rho_0A_0}{E_0I_{y0}}},
\qquad
\Lambda=\sqrt{\Omega},
\]

\[
A_0=b_0h_0,
\qquad
I_{y0}=\frac{b_0h_0^3}{12}.
\]

Приняты

\[
E_0=1,\quad \nu_0=0.3,\quad \rho_0=1,\quad
b_0=0.20,\quad h_0=0.05,\quad l=1,
\]

поэтому \(\Omega/\omega=69.2820323027551\). В CSV отдельно сохраняются
\(\omega\), \(\Omega\) и \(\Lambda\); на обеих вертикальных осях показана
\(\Lambda\).

## Геометрический contract

Фактические размеры плеч определяются формулами

\[
L_1=l(1-\mu),\qquad L_2=l(1+\mu),
\]

\[
h_1=h_0(1-\tau),\qquad h_2=h_0(1+\tau),
\qquad b_1=b_2=b_0.
\]

Таким образом, при \((\mu,\tau)=(0.5,0.2)\) получены
\(L_1=0.5\), \(L_2=1.5\), \(h_1=0.04\) и \(h_2=0.06\). Это прямоугольный
thickness split, а не прежняя mass-preserving параметризация круглых
стержней. Дополнительная нормировка массы не вводится.

## Материальные модели

Модели Эйлера--Бернулли и Тимошенко сохраняют изотропные параметры
\(E_0\), \(\nu_0\) и \(\rho_0\). Для модели Тимошенко принят
\(K=5/6\). Эквивалентный изотропный модуль по результатам RLB не подбирается.

Каждое плечо RLB состоит ровно из четырёх равных слоёв

\[
[0/90/90/0],\qquad h_{\mathrm{ply},i}=h_i/4.
\]

Материал слоя соответствует case A:

\[
\delta=0.1,\quad E_1=1.1,\quad E_2=0.9,\quad \nu_{12}=0.3,
\]

\[
G_{12}=G_{13}=G_{23}=\frac{1}{2.6},\qquad \rho=1.
\]

Для каждого плеча выполняется обычная цепочка
\(Q\rightarrow\overline Q\rightarrow A/B/D\), после чего вычисляются
сдвиговые и массовые характеристики и одномерные редуцированные свойства.
One-ply shortcut не используется.

## Представление EB при разных толщинах плеч

Frozen EB determinant допускает разные длины через \(\mu\), но содержит
только один параметр толщины. Поэтому на сетке по \(\mu\), где \(\tau=0\),
сохраняется прежний sign scan. Для сетки по \(\beta\) применяется узкий
analysis-local physical-state adapter в порядке
\([u,w,\psi,N,Q,M]\):

\[
u'=\frac{N}{EA},\qquad w'=-\psi,\qquad
\psi'=\frac{M}{EI},
\]

\[
N'=-m\omega^2u,\qquad Q'=-m\omega^2w,\qquad M'=Q.
\]

Здесь для каждого плеча

\[
EA_i=E_0b_ih_i,\qquad
EI_i=\frac{E_0b_ih_i^3}{12},\qquad
m_i=\rho_0b_ih_i.
\]

Используются прежние внешние заделки и замороженная physical joint matrix.
В равномерном пределе \(\tau=0\) два EB determinant связаны точным
тождеством

\[
\det D_{\mathrm{phys}}=
-\frac{l^7}{16(E_0I_{y0})^3\Lambda^7}\det D_{\mathrm{frozen}}.
\]

Максимальный относительный residual трёх off-root проверок равен
\(1.99\cdot10^{-13}\) при пороге \(10^{-10}\). Новый production solver не
создаётся; adapter находится только в analysis entry point.

## Root inventory и графики

Для EB на обеих сетках используется frozen sign-scan algorithm с независимым
повтором на вдвое более мелкой сетке. При \(\tau=0.2\) ему передаётся
положительно масштабированный determinant physical-state adapter; такое
масштабирование не изменяет нули и знак determinant. Для old Timoshenko и weak
RLB сохраняются прежняя determinant/SVD policy, primary/verification
уточнение и замороженные singular- и boundary-gates.

Исторически рассчитанные точки сохраняют свой первоначальный расширенный
inventory. Для новых closing-точек production contract `spectral-sweep-runner-v2`
равен ровно позициям 1--8 и root 9 guard; roots 10--13 не вычисляются.
Этот факт записывается как `NOT_COMPUTED_ABOVE_ROOT9` и не подменяется
заключением о внутреннем хвосте. В итоговые таблицы выводятся только
позиции 1--8 и root 9 guard.

Итоговые файлы:

- `lambda_vs_mu_plot.png` — \(\Lambda(\mu)\) при
  \(\beta=15^\circ\), \(\tau=0\);
- `lambda_vs_beta_plot.png` — \(\Lambda(\beta)\) при
  \(\mu=0.5\), \(\tau=0.2\).

На каждом рисунке восемь цветов соответствуют независимо упорядоченным
позициям. EB показана сплошными линиями, прежняя модель Тимошенко —
пунктирными, weak RLB — штрихпунктирными. Относительные расхождения моделей
не вычисляются.

## Closing audit

Перед закрытием этапа partial CSV проверяются по ключу
`(sweep, model, parameter value, sorted position)`. Каждая завершённая точка
должна содержать ровно позиции 1--8 и root 9 guard. Дубликаты, пересекающиеся
worker outputs и неполные девятистрочные группы не допускаются.

Полностью рассчитанный beta sweep используется без повторного решения. Его
рисунок строится непосредственно из трёх существующих CSV. После `PASS`
fast/full gate три точки, для которых во время валидации не было frozen
reference, переносятся из целостных validation shards. Оставшиеся
mu-points вычисляются `spectral-sweep-runner-v2` в режиме
`--missing-only`.

Расчёт closing-точек выполняется одним последовательным Python worker без
multiprocessing при
`OMP_NUM_THREADS=MKL_NUM_THREADS=OPENBLAS_NUM_THREADS=NUMEXPR_NUM_THREADS=1`.
Каждая точка проходит локальное primary/verification-уточнение либо
полный fallback по frozen policy. Результат сначала записывается во временную
транзакцию, затем canonical CSV заменяется атомарно. Перед и после merge
проверяются semantic hashes всех ранее готовых групп. Повторный расчёт
готовой точки запрещён.

Для новых points closing diagnostic сохраняет primary/verification agreement
отдельно для positions 1--8 и root 9. Ранее сформированные CSV содержат только
aggregate maximum по positions 1--9. Если этот aggregate не проходит frozen
threshold, без повторного расчёта нельзя установить, относится qualification
к plotted positions, root 9 или к обоим подмножествам. Такие случаи
классифицируются консервативно и не смешиваются с qualifications, начинающимися
строго выше root 9.

## Ограничения

Результат относится только к двум объявленным конечным сеткам, case A и
\(\delta=0.1\). Не рассматриваются другие законы изменения \(\mu\), \(\tau\)
или толщины, другие укладки и материалы. Не выполняются сопоставление форм,
MAC, анализ сближения частот, Ritz, FEM, кручение и демпфирование. Подготовка
статьи не входит в этот этап. Production physics и исторические результаты не
изменяются.

# Независимая проверка расхождений с Table 4.3.3 методом Рэлея—Ритца

## Область проверки

Этап RLB-0A-S1 выполнен 24 августа 2026 г. для одного прямого симметрично
слоистого стержня. Governing equations, эффективные свойства
\(D=D_{\mathrm{bending}}\), \(S=S_{\mathrm{shear}}\), \(m\), \(J\), значение
\(K=5/6\), исходные значения Table 4.3.3 и напечатанный допуск \(0{,}0005\)
оставлены без изменения. Исходный отчёт RLB-0 и две существующие PNG также не
изменялись. Выводы этапа условны относительно ранее принятого \(K=5/6\) с
provenance `INFERRED_FROM_INTERNAL_NUMERICAL_CONSISTENCY`; повторная
калибровка \(K\) не выполняется.

Проверка охватывает 72 модельных случая: 54 опубликованные direct-FSDT строки
и 18 project diagnostics с отсутствующим в источнике значением без
вращательной инерции. Для каждой комбинации ламината, граничных условий и
\(a/h\) рассчитаны варианты с \(J>0\) и с \(J=0\). Сопряжённые стержни и
угловой узел в этот этап не входят.

## Вариационная постановка

Для гармонических амплитуд \(w(x)\) и \(\psi_b(x)\) использованы функционалы

\[
 U=\frac12\int_0^L\left[
 D(\psi_b')^2+S(w'+\psi_b)^2
 \right]dx,
\]

\[
 T=\frac12\int_0^L\left[
 m\dot w^2+J\dot\psi_b^2
 \right]dx.
\]

При \(s=x/L\), \(W=w/L\),
\(\gamma=SL^2/D\), \(\rho_r=J/(mL^2)\) безразмерная задача имеет вид

\[
 \mathbf K\boldsymbol q=\Lambda\mathbf M\boldsymbol q,
 \qquad
 \Lambda=\frac{\omega^2mL^4}{D},
\]

\[
 \mathcal K=\int_0^1\left[
 (\psi_{b,s})^2+\gamma(W_{,s}+\psi_b)^2
 \right]ds,
 \qquad
 \mathcal M=\int_0^1\left[W^2+\rho_r\psi_b^2\right]ds.
\]

Transfer matrices, matrix exponentials, характеристические уравнения Reddy и
существующий root finder в сборке или решении этой собственной задачи не
используются. Производственный модуль применяется только для получения
замороженных reduced properties и для последующего сравнения уже найденных
Ritz roots.

## Базис и граничные условия

Пробные функции построены из shifted-Legendre polynomials. Существенные
условия задаются множителями, а естественные условия не встраиваются в базис:

| Условия | Базис для \(W\) | Базис для \(\psi_b\) | Естественные условия |
|---|---|---|---|
| HH | \(s(1-s)P_n(2s-1)\) | \(P_n(2s-1)\) | \(M(0)=M(L)=0\) |
| CC | \(s(1-s)P_n(2s-1)\) | \(s(1-s)P_n(2s-1)\) | отсутствуют |
| CF | \(sP_n(2s-1)\) | \(sP_n(2s-1)\) | \(Q(L)=M(L)=0\) |

Проверены порядки \(N=4,6,8,10,12\). Guard \(N=16\) потребовался только для
двух случаев: `90_deg__CC__a_h_100__with_RI` из-за quality gate при \(N=12\)
и `90_deg__CF__a_h_100__with_RI` из-за сходимости \(N=10\to12\). В обоих
случаях переход \(N=12\to16\) прошёл порог \(10^{-8}\). Интегралы вычислены
фиксированной 48-точечной квадратурой Гаусса—Лежандра. Для максимальной
степени \(N=16\) подынтегральные полиномы имеют степень не выше 34, тогда как
эта квадратура точно интегрирует полиномы до степени 95.

Оба coupling blocks интегрированы независимо. До удаления машинной
асимметрии максимальные symmetry residuals матриц жёсткости и массы равны
соответственно \(1{,}03\cdot10^{-16}\) и \(5{,}66\cdot10^{-17}\). Все матрицы
жёсткости после существенных условий и все полные матрицы массы при \(J>0\)
положительно определены. Нулевые моды не обнаружены.

## Точное исключение вращательной переменной при \(J=0\)

При \(J=0\) блок массы для \(\psi_b\) оставлен строго нулевым. Использована
статическая конденсация

\[
 \mathbf K_{\mathrm{eff}}=\mathbf K_{ww}
 -\mathbf K_{w\psi}\mathbf K_{\psi\psi}^{-1}\mathbf K_{\psi w},
 \qquad
 \mathbf K_{\mathrm{eff}}\boldsymbol a
 =\Lambda\mathbf M_{ww}\boldsymbol a.
\]

После решения восстановлено
\(\boldsymbol b=-\mathbf K_{\psi\psi}^{-1}
\mathbf K_{\psi w}\boldsymbol a\). Максимальный residual статической
конденсации равен \(7{,}83\cdot10^{-17}\), а максимальный residual
восстановленной полной двухполевой моды — \(2{,}57\cdot10^{-11}\). Малое
искусственное значение \(J\) не вводилось.

## Проверка вращательной инерции

Для любой допустимой формы \(q\)

\[
 R_J(q)=\frac{U(q)}{T_{\mathrm{trans}}(q)+J,T_{\mathrm{rot}}(q)}.
\]

Если \(J_2\ge J_1\ge0\), то \(R_{J_2}(q)\le R_{J_1}(q)\) для любой формы.
По минимаксному принципу упорядоченные собственные частоты не возрастают при
увеличении вращательной инерции. Все 36 transfer-пар и все 36 Ritz-пар
удовлетворяют этому условию с численным допуском \(10^{-12}\).

## CC: Eq. (4.3.51)

Проверены 24 случая CC: четыре ламината, три значения \(a/h\), с \(J>0\) и
с \(J=0\). Для конечного \(J\) Eq. (4.3.51) вычисляется в устойчивой форме

\[
 G_{CC}=2AB(\cos x-\operatorname{sech}y)
 +(B^2-A^2)\sin x\tanh y,
\]

где \(A=S_{11}\), \(B=S_{22}\), \(x=\lambda L\), \(y=\mu L\); выражение
масштабируется на \(\max(|A|,|B|)^2\). При \(J=0\)

\[
 S_{11}=-S\mu^3,\qquad S_{22}=S\lambda^3,
\]

\[
 G_{CC}^{(0)}=2\lambda^3\mu^3(\cos x-\operatorname{sech}y)
 +(\mu^6-\lambda^6)\sin x\tanh y.
\]

Для предотвращения потери точности \(\mu^2\) вычисляется из произведения
корней как \(\mu^2=r/(D\lambda^2)\). Eq. (4.3.51), physical transfer root и
Ritz root прошли во всех 24 случаях; расхождение Eq. (4.3.51)/transfer равно
не более \(1{,}63\cdot10^{-13}\). Поиск на фиксированной 4001-точечной сетке
ниже fundamental root не выявил spurious roots.

## CF и Problem 4.14

Для state \(\boldsymbol y=[w,\psi_b,Q,M]^{\mathsf T}\),
\(\boldsymbol y'=\mathbf A\boldsymbol y\), определены

\[
 \mathbf E=[\boldsymbol e_Q,\boldsymbol e_M],\qquad
 \mathbf R=\begin{bmatrix}\boldsymbol e_Q^{\mathsf T}\\
 \boldsymbol e_M^{\mathsf T}\end{bmatrix}.
\]

Из условий \(w(0)=\psi_b(0)=0\), \(Q(L)=M(L)=0\) следует

\[
 F_{CF}(\omega)=\det\!\left(
 \mathbf R\exp(\mathbf A L)\mathbf E
 \right)=0.
\]

Эта характеристика применяется только после независимого Ritz solve. Все 24
CF-случая прошли: максимум first-root/transfer равен
\(7{,}65\cdot10^{-14}\), максимум transfer/Ritz —
\(2{,}43\cdot10^{-10}\); более ранние physical или spurious roots не
обнаружены.

В напечатанном Problem 4.14 используются обозначения

\[
 R_1=\beta\widetilde I_0\omega^2+S-\lambda^2D,\quad
 R_2=\beta\widetilde I_0\omega^2+S+\mu^2D,
\]

\[
 S_1=\widetilde I_0\omega^2-\lambda^2S,\quad
 S_2=\widetilde I_0\omega^2+\mu^2S.
\]

Символ \(\beta\) в контексте задачи не определён, хотя вращательная инерция
объявлена отброшенной. Диагностика поэтому имеет статус
`UNDEFINED_SYMBOL_IN_PRINTED_PROBLEM_4_14`; значение \(\beta\) по таблице не
подбиралось, а Problem 4.14 не использовался как исполняемое уравнение.

## Научный вывод и ограничения

Transfer и Ritz roots совпали для HH, CC и CF; natural-BC residuals и точная
конденсация при \(J=0\) прошли установленные gates. Вместе с проверками
Eq. (4.3.51) и физического CF determinant это не подтверждает ошибку governing
equations, transfer formulation или граничных условий в пределах замороженной
одномерной модели.

Новый Ritz-аудит использует те же замороженные \(D,S,m,J\) и потому сам по
себе не является независимым повторным выводом laminate reduction. Основанием
для исключения обнаруженной ошибки reduced properties остаются gates RLB-0:
максимальное различие compliance/Schur \(5{,}97\cdot10^{-16}\) и partition
invariance \(2{,}13\cdot10^{-16}\). Совокупность этих результатов указывает
на численную несогласованность части Table 4.3.3 с проверенной моделью. Это не
доказывает наличие опечатки и не вводит `CORRECTED_VALUE`; исходные значения
сохранены как `SOURCE_TABLE_INCONSISTENCY`.

HH/RI controls участвовали в прежнем численном обосновании принятого
\(K=5/6\). Поэтому их совпадение в этом этапе не считается независимой
повторной проверкой или новой калибровкой \(K\).

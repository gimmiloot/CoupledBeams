Теперь рассчитаны только A/.005 и C/.005. Четыре остальные точки
прочитаны из K18 с исходным происхождением K16/K17. Исторические отказы
K16 и результаты K17/K18 не переписаны.

Сохранены H/L/L/H EB, chi=.4, b=.20,h=.05,L1=L2=1,mu=0,kappa=1.
Штатная редукция вновь даёт A=.011,D=2.979166666666667e-6,m=.01;
в EB 1/S=J=0. Reference K12: t_ref=69.2820323027551,
k_theta=2.083333333333334e-6; при d=.005 c_theta=7.216878364870325e-7.
Приняты p=−alpha+i*omega_d и z=p*t_ref=−a+i*Omega_d;
частота — Im(p), а не |p|.

Использован неизменный `production.solve_mode(..., solver_path='reduced',
eta=+1)`. Первый predictor — подтверждённый комплексный корень при .001.
Обе прямые попытки .001→.005 приняты; дополнительный weak predictor
не понадобился. Промежуточных d и независимого full Newton нет.
После каждого принятого reduced-корня выполнены одна full-реконструкция
и диагностика при том же p. Архитектура, масштабирование и gates не менялись.

и по zeta при обоих d. Для zeta отношение A:B:C составляет
35.1588:15.4271:1 при .001 и 35.2076:15.4815:1 при .005.
Для a соответствующие отношения — 26.9194:2.97068:1 и 26.9740:2.98131:1.

При увеличении d оба нормированных наклона уменьшаются у всех трёх форм,
а относительное отклонение от упругого предиктора увеличивается.
Изменение a/d между двумя точками: A −.16163%, B −.007082%, C −.36385%;
изменение zeta/d: −.22758%, −.014584%, −.36582% соответственно.
Наибольшая **относительная** поправка наблюдается у C, затем у A.
Следовательно, предположение о наиболее раннем относительном отклонении
STRONG в этой выборке не подтверждается. Названия классов отражают
величину чувствительности, а не гарантированный порядок точности
первого приближения. В абсолютной величине затухание A остаётся наибольшим.

Упругая форма предсказывает знак, порядок и величину эффекта: максимальное
отклонение наклона при .005 составляет .3811%. Это количественная
характеристика шести решений, не новый порог применимости. Для .001
сохранён прежний описательный gate K16 в 1%; при .005 используется
`DESCRIPTIVE_ONLY`, без введённой после расчёта границы «работает/не работает».

## 5. Частотный сдвиг

Относительные сдвиги при .005 равны .0620874% для A, .00650773% для B
и .00205314% для C. Они меньше соответствующих zeta: δ/zeta составляет
.05337, .01272 и .06214. Сравниваются безразмерные величины; размерный
alpha не сопоставляется непосредственно с относительным сдвигом.

Коэффициенты δ/d² между точками меняются на +.0561%, +.00973% и −.3525%.
Близость согласуется с квадратичной ведущей поправкой, однако два d
не доказывают порядок. У C при .001 сдвиг 8.24e-7 ниже общего частотного
ориентира 1e-6. Поэтому небольшое изменение его δ/d² нельзя считать
самостоятельно разрешённым физическим отклонением от квадратичного закона.
Новый расчёт или дополнительное уточнение ради этого не выполнялись.

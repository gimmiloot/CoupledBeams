## Постановка и реализация

Основание — [теоретическая заметка](inplane_rotational_spring_joint.md), разделы
«Шесть условий и матрица узла», «Независимый вывод EB», «Пределы» и
«Характеристическая постановка». Сохранён
[физический координатный контракт](reddy_inplane_coordinate_contract.md): обе
оси идут от внешних заделок к узлу, `y=[u,w,psi,N,Q,M]`, угол публичного API в радианах.
Поступательная связь остаётся жёсткой; точечная безмассовая ненапряжённая пружина
действует только на `Delta_psi=psi1-psi2`. Вязкость, эксцентриситет и масса узла отсутствуют.

В [inplane_rotational_spring_eb.py](../../scripts/lib/inplane_rotational_spring_eb.py)
подготовлены `EBArm`, `Joint`, `state_matrix`, `transfer_matrix`,
`clamp_to_joint_map`, `joint_matrix`, `boundary_assembly`, `endpoint_diagnostics`.
`A,D,m,L` должны быть конечными и положительными; `A` — продольная жёсткость,
`D` — изгибная жёсткость. `SPRING` требует явного конечного `k_theta>=0`;
`RIGID` требует `k_theta=None` и вызывает прежнюю матрицу жёсткого узла.
Нулевая пружина, отсутствие параметра и точный `RIGID` различаются.

Уравнения состояния классической EB:

```text
u'=N/A; w'=-psi; psi'=M/D;
N'=-m*omega^2*u; Q'=-m*omega^2*w; M'=Q.
```

При `c=cos(beta)`, `s=sin(beta)` шесть строк на концах `x_i=L_i`:

```text
u1+c*u2+s*w2=0
w1-s*u2+c*w2=0
M1+k_theta*(psi1-psi2)=0
N1-c*N2-s*Q2=0
Q1+s*N2-c*Q2=0
M1+M2=0.
```

Пять строк сохранены из
[reddy_symmetric_coupled_beams.py](../../scripts/lib/reddy_symmetric_coupled_beams.py),
`joint_matrix`; для `RIGID` третья строка остаётся `psi1-psi2=0`.
Пружинная строка имеет ненулевые элементы `(3,6,9)=(k_theta,1,-k_theta)`
при нумерации столбцов с 1. Минор по столбцам `(1,2,4,5,6,12)` равен 1.
Теоретическое тождество работы сохраняется: `delta W_arms=-delta U_J`,
`delta W_arms+delta U_J=0`. Прежняя атрибуция ошибочного минуса заданию снята
в теоретической заметке, RLB-K05, текущем контексте и CHANGELOG; формулы не менялись.

Новый модуль изолирован от старых входных функций. Старые defaults, state/joint
матрицы и результаты не редактировались. Импорт общих геометрических и численных
функций не означает реализацию нового узла Reddy/FSDT.

## Масштабирование и заранее заданные критерии

Для каждого плеча используется `Z_i=diag(L_i,L_i,1,A_i,D_i/L_i^2,D_i/L_i)`:
`T_i=Z_i exp(Z_i^-1 H_i Z_i L_i) Z_i^-1`, `P_i=T_i[:,3:6]` (индексы Python).
Физическая граничная матрица `B=J_theta blockdiag(P1,P2)` имеет размер 6×6.
Численные неизвестные — реакции заделок, делённые на `Z_i[3:6]`.

Единицы строк: `(l,l,D_ref/l,D_ref/l^2,D_ref/l^2,D_ref/l)` для пружины;
у `RIGID` единица третьей строки равна 1. После этого пружинная строка
делится на `max(1,kappa_theta)`, где `kappa_theta=k_theta*l/D_ref`.
Размерный `k_theta` не складывается с числом 1. Нулевая жёсткость не является
делителем. Далее применяется существующая `positively_equilibrate_matrix`.
Все преобразования обратимы; положительные множители строк умножают
определитель на ненулевой множитель и аналитически сохраняют его нули.

Для восстановления применяется обратное преобразование столбцов SVD, затем
масштаб реакций; сохраняются концевые состояния всех обнаруженных нуль-векторов.
Амплитуда нормируется по единицам состояния `(l,l,1,D_ref/l^2,D_ref/l^2,D_ref/l)`.
Шесть физических остатков вычисляются отдельно скалярными формулами и делятся
на фиксированные единицы строк, **без** делителя `max(1,kappa_theta)`.
Так большая жёсткость не скрывает ошибку закона пружины малым `Delta_psi`.
Концевые состояния служат только диагностикой; формы и модальная классификация не строятся.

Допуски записаны до получения результатов:

| Проверка | Критерий |
| --- | --- |
| `sigma_min/sigma_max` полной масштабированной матрицы | ≤ `1e-9` |
| Строгая численная nullity | `sigma_j/sigma_max ≤ 1e-12` |
| Невязка нуль-вектора относительно `||B||_F ||v||` | ≤ `1e-9` в обоих численных представлениях |
| Поступательная совместность в физических единицах строк | ≤ `1e-10` |
| Все физические строки; оба момента при шарнире | ≤ `1e-9` |
| Относительная частотная разность контрольных постановок | ≤ `1e-9` |
| Допустимое отрицательное приращение sorted частоты | не ниже `-1e-9` относительно предыдущей |
| Алгебра матриц/энергии в целевых тестах | `1e-12` |

Критерии сингулярности, nullity, совместности, равновесия и частотного сравнения
взяты из `THRESHOLDS` существующего
[матричного пилота](../../scripts/analysis/laminated_beams/pilot_reddy_symmetric_coupled_beams_beta0.py).
Новый критерий монотонности использует тот же относительный допуск частот:
положительное приращение энергии пружины при неизменной массе даёт неубывание
упорядоченных собственных частот по минимаксному принципу. Строгий рост не требуется.
Допуски не подбирались по результатам; их достижимость новой реализацией не проверена.

## Конечный набор и поиск

Reference, а не прототип устройства: `L1=L2=l=1`, `b=.20`, `h=.05`, `E=rho=1`;
`Ag=b*h`, `Ig=b*h^3/12`, `A=E*Ag`, `D=D_ref=E*Ig`, `m=rho*Ag`.
`Omega=omega*l^2*sqrt(rho*Ag/(E*Ig))`, `Lambda=sqrt(Omega)`.

[Entry point](../../scripts/analysis/laminated_beams/pilot_inplane_rotational_spring_eb.py)
задаёт локальный `frequency-map-v1/fast_plot`, `sorted_positions` по
[общей политике](../numerics/frequency_map_computation_policy.md). Это отдельный
диагностический сценарий новой физики и нового контракта выходных данных,
а не пресет материала прежнего RLB-runner; общие solver defaults не меняются.
Переиспользованы `_scan_candidates` и его локальный refiner; полный inventory
прежнего пилота не вызывается. Зависимость от внутреннего API helper является
техническим ограничением этого небольшого адаптера.

Подготовленный режим: сначала `beta=30°, kappa=1`, затем остальные группы
последовательно. Окна шириной до `4` по Omega, шаг не грубее `0.0625`, перекрытие
`0.125`, нижняя граница `1e-8`, аварийный потолок `240`. Оба detector работают
на каждом покрытом интервале; соседние результаты только смещают границы окон.
Подозрение вызывает один локальный повтор с более мелкой и сдвинутой сеткой.
Неустранённые кандидаты останавливают группу. Лимит `120 s` проверяется между
окнами; он не является измеренной стоимостью или гарантией длительности одного окна.

Остановка — после нахождения семи позиций с расстоянием guard от правого края
окна больше `0.02`. Дополнительное окно/хвост над найденным guard не запускается;
неизбежная часть последнего окна справа от guard фиксируется в diagnostics.
Это конечный detector-контроль, не теорема полноты. `consolidate` допускает
объединение повторных обнаружений только при перекрытии интервалов, согласованной
nullity и расстоянии ≤64 ULP; прочие близкие кандидаты требуют локального
разрешения. Кратность берётся из nullity, не из числа обнаружений. Если кратный
корень пересекает границу guard, группа останавливается без усечения кратности.
Надёжность этих численных правил ещё не проверена запуском.

## Контрольные проверки и их статус

Все перечисленные программные проверки **NOT_RUN_ENVIRONMENT**:

- [Целевые тесты](../../tests/test_inplane_rotational_spring_eb.py): шесть скалярных
  условий, пять прежних строк, работа и гессиан пружины, шарнир/RIGID,
  минор/ранг, EB state, масштабирование, обратный перевод реакций, валидация входа,
  отделение продольного блока при beta=0, сохранение неразрешённых близких кандидатов.
- На каждом корне: полная матрица, nullity, нуль-вектор и шесть физических остатков;
  при шарнире дополнительно оба момента. Численные maxima пока отсутствуют.
- Независимый прямой RIGID reference: объединение продольных
  `omega_n=n*pi/(2*l)*sqrt(A/m)` и изгибных корней `cos(z)-1/cosh(z)=0`,
  `Omega=z^2/4`, для длины `2*l`, только в диапазоне guard.
- RIGID regression при обоих углах: семь локальных окрестностей старой
  `assemble_clamped_coupled_matrix`, `mu=0`, `eps=h/(sqrt(12)*l)` и аргумент
  `Lambda=sqrt(Omega)`. Совместимость следует из раздела
  [«Представление EB при разных толщинах плеч»](rectangular_weakly_orthotropic_mu_beta_graphs_note.md).
  Это регрессия с общим detector, не полностью независимая верификация.
- При beta=0 проверяются только продольные частоты, попавшие под guard данной
  группы. Их sorted index может меняться; пустой диапазон получает `NOT_IN_RANGE`.
  Спектр двух независимых консолей не используется как reference шарнира.
- Для `kappa=100,10000` сохраняются реальные относительные отличия первых шести
  частот от RIGID и проверяется уменьшение этих отличий с допуском `1e-9`.
  Равенство конечной пружины точному RIGID не требуется. Проверяется неубывание
  sorted частот по всей последовательности жёсткостей.
- Для представительной группы — отдельное локальное уточнение семи корней после
  положительного умножения строк на `(2,.5,3,1/3,5,.2)` и проверка физических остатков.

Тесты строк/энергии/масштабирования и невязки являются проверками внутренней
согласованности. Одиночные характеристические уравнения дают независимый
прямой reference. Этот конечный набор не составляет полной независимой
верификации произвольного углового упругого соединения; RLB-спектры не затрагиваются.

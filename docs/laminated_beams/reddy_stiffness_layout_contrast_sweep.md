# RLB-2E: карта контраста жёсткости

## Цель и область расчёта

Рассматриваются первые восемь независимо упорядоченных частот двух жёстко
сопряжённых симметрично слоистых стержней. Параметр \(\chi\) задаёт контраст
между жёсткой и мягкой версиями одного базового материала. Геометрия
конструкции, плотность и количество каждого материала при этом не меняются.

Этап RLB-2E является конечной частотной картой, построенной по общей
политике [`frequency-map-v1`](../numerics/frequency_map_computation_policy.md).
На каждой точке рассматриваются независимо отсортированные значения. Формы,
идентичность модальных ветвей, MAC и распределение энергии не вычисляются.

## Геометрия и материал

Использован фиксированный геометрический контракт

\[
\mu=\tau=0,\qquad \beta=30^\circ,\qquad L_1=L_2=l=1,
\]

\[
b_1=b_2=0.20,\qquad h_1=h_2=0.05,\qquad K=5/6.
\]

В каждом плече находятся четыре равных слоя толщины
\(h_{\mathrm{ply}}=0.0125\). Ориентация материала во всех слоях равна
\(0^\circ\). Стопки задаются снизу вверх в проектной координате.

Базовый материал \(M_0\) соответствует weakly orthotropic case A:

\[
E_{1,0}=1.1,\quad E_{2,0}=0.9,\quad \nu_{12,0}=0.3,
\]

\[
G_{12,0}=G_{13,0}=G_{23,0}=1/2.6,\qquad \rho_0=1.
\]

Для материала H все модули упругости умножаются на \(1+\chi\), а для
материала L — на \(1-\chi\). Коэффициент Пуассона и плотность остаются
равными значениям базового материала. Поэтому при \(\chi=0\) материалы H и
L совпадают, а при \(\chi=0.8\) отношение соответствующих модулей равно 9.

## Расположение материалов

Исследованы три конфигурации:

- `BOTH_OUTER_STIFF`: H/L/L/H в обоих плечах;
- `BOTH_INNER_STIFF`: L/H/H/L в обоих плечах;
- `ANTI_PHASE`: L/H/H/L в первом плече и H/L/L/H во втором.

Все стопки палиндромны. Поэтому каждый отдельный ламинат остаётся
симметричным относительно своей средней плоскости.

## Конститутивная проверка

Для общей ориентации слоёв матрицы жёсткости материалов связаны
соотношениями

\[
Q_H=(1+\chi)Q_0,\qquad Q_L=(1-\chi)Q_0.
\]

Интегрирование по четырём равным слоям даёт

\[
\frac{D_{\mathrm{outer}}}{D_0}=1+\frac{3\chi}{4},\qquad
\frac{D_{\mathrm{inner}}}{D_0}=1-\frac{3\chi}{4},
\]

\[
D_{\mathrm{outer}}+D_{\mathrm{inner}}=2D_0.
\]

Эти формулы проверены для полной матрицы \(D\), а также после одномерной
редукции. Максимальный относительный residual полной формулы равен
\(1.7114\cdot10^{-16}\). Максимальный residual редуцированной формулы равен
\(3.4161\cdot10^{-16}\).

При всех значениях \(\chi\) перестановка слоёв сохраняет

\[
A_{\mathrm{beam}}=0.011,\qquad
S_{\mathrm{beam}}=0.0032051282051282055,
\]

\[
m=0.01,\qquad J=2.083333333333334\cdot10^{-6}.
\]

При \(\chi=0\) получено
\(D_0=2.2916666666666675\cdot10^{-6}\). Характерные отношения изгибной
жёсткости приведены ниже.

| \(\chi\) | \(D_{\mathrm{outer}}/D_0\) | \(D_{\mathrm{inner}}/D_0\) |
| ---: | ---: | ---: |
| 0.0 | 1.0 | 1.0 |
| 0.4 | 1.3 | 0.7 |
| 0.8 | 1.6 | 0.4 |

Максимальные относительные остатки \(B\) и \(I_1\) равны соответственно
\(1.4832\cdot10^{-17}\) и нулю. Конститутивная проверка получила статус
`PASS` до построения спектра.

```yaml

neighbour_audit: enabled
local_repair_policy: triggered_only
strict_audit_default: false
branch_tracking: false

```

При \(\chi=0\) выполнен один расчёт, который затем использован для трёх
конфигураций с явным указанием происхождения данных. Прогноз по соседним
точкам определяет только локальные интервалы поиска. Каждое сохранённое
значение получено из замороженной характеристической матрицы с существующими
determinant/SVD detector и refiner.

В каждой группе сохранены позиции 1--8 и контрольный root 9. Последний не
показан на рисунке и служит только для проверки полноты.

Корни с позициями 10 и выше не вычислялись и не сохранялись.

## Нормировка

Использована нормировка RLB-2D:

\[
A_0=b_0h_0,\qquad I_{y0}=\frac{b_0h_0^3}{12},
\]

\[
\Omega=\omega l^2\sqrt{\frac{\rho_0A_0}{E_0I_{y0}}},\qquad
\Lambda=\sqrt{\Omega},
\]

где \(E_0=\rho_0=l=1\), \(b_0=0.20\) и \(h_0=0.05\). Нормировка не
зависит от \(D_0\), \(D_{\mathrm{outer}}\) или
\(D_{\mathrm{inner}}\), поэтому исследуемое изменение жёсткости не
исключается из частотного параметра.

## Результаты карты

Для каждой конфигурации получено 41 значение \(\chi\). Основная таблица
содержит 123 полные группы и 1107 строк.

Все 123 контрольных root 9 прошли проверки полноты, порядка и качества. При
размещении жёстких слоёв снаружи все восемь упорядоченных частот возрастают
на принятой сетке. При размещении жёстких слоёв внутри все восемь значений
уменьшаются.

Конфигурация `ANTI_PHASE` даёт смешанное изменение упорядоченных позиций.
Это наблюдение относится только к sorted spectrum и не определяет
идентичность мод. Минимальные соседние интервалы равны:

- `BOTH_OUTER_STIFF`: \(\Delta\Lambda=0.276073\) при \(\chi=0.30\)
  между позициями 6 и 7;
- `BOTH_INNER_STIFF`: \(\Delta\Lambda=0.00528821\) при \(\chi=0.72\)
  между позициями 3 и 4;
- `ANTI_PHASE`: \(\Delta\Lambda=0.400533\) при \(\chi=0.80\) между
  позициями 7 и 8.

Эти интервалы являются кандидатами для возможного последующего анализа
форм и энергии. По текущей карте нельзя установить пересечение, veering,
обмен модальным характером или локализацию.

## Численная диагностика

До основного расчёта измерены три production anchors. Их времена составили
1.5295, 1.6866 и 1.5276 s. Консервативная оценка оставшегося времени была
равна 298.5 s при лимите 2700 s, поэтому расчёт продолжен автоматически.

Полное измеренное время workflow составило 114.0 s, включая локальные
проверки, arm-swap diagnostic и построение рисунка. Максимальный RSS равен
150003712 bytes, или 143.1 MiB.

Выполнено 408135 determinant evaluations и 408135 SVD/sigma evaluations.

Контроль соседних значений отметил 13 точек. Для них выполнено 13 локальных
повторных расчётов, которые воспроизвели исходные значения; сохранено 117
строк `LOCAL_REFINEMENT`. Неразрешённых точек нет, сглаживание не
применялось. Максимальные значения \(\sigma_{\min}/\sigma_{\max}\) и
boundary residual среди базовых корней равны соответственно
\(1.0783\cdot10^{-17}\) и \(2.1214\cdot10^{-16}\).

Перестановка плеч конфигурации `ANTI_PHASE` проверена при \(\chi=0.4\) и
0.8. Максимальные относительные различия по \(\Omega\) равны
\(3.0951\cdot10^{-13}\) и \(6.9263\cdot10^{-12}\) при допуске
\(10^{-8}\). Проверка получила статус `PASS`.
